# Aditya Sanju | Portfolio

A personal portfolio website for **Aditya Sanju**, a B.Tech Computer Science and Engineering student at Lovely Professional University, focused on AI/ML, computer vision and data analytics.

**Live site:** `https://AdityaSanju-prog.github.io/<repo-name>/` *(replace with your link after deploying)*

---

## Features

- Animated node-network background that reacts to the cursor
- Terminal-style hero with a typing effect
- Dark and light themes, with a toggle and automatic system detection
- Sections for skills, projects, certificates and activities, education and contact
- Contact buttons that open Gmail compose, addressed to me, in the visitor's own account
- Responsive layout for phones, tablets and desktops
- Keyboard-friendly, with visible focus states, and respects reduced-motion settings
- A single HTML file with no build step and no dependencies

## Run locally

```bash
git clone https://github.com/AdityaSanju-prog/<repo-name>.git
cd <repo-name>
```

Open `index.html` in any browser. No installation is needed.

## Deploy with GitHub Pages

1. Rename the portfolio file to `index.html` and push it to your repository.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save.
4. After a minute or two, your site is live at `https://AdityaSanju-prog.github.io/<repo-name>/`.

## Customize

- **Content:** edit the text directly in `index.html`. Each section is marked by its `id` (`skills`, `projects`, `learning`, `education`, `contact`).
- **Colors:** change the variables at the top of the `<style>` block (`--bg`, `--a`, `--b` and so on).
- **Contact email:** search for `adityasanju7@gmail.com` and replace it.
- **Typing lines:** edit the `words` array in the script.
